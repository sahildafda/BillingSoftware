1. Before you begin

MotoDhandho is a Windows desktop application for products, customers, suppliers, billing, reports, and business data.

What you need

  • A Windows 10 or Windows 11 computer.
  • The installer file named Billing-Software-Setup-1.0.1.exe or the latest version supplied to you.
  • An internet connection for account verification and application updates.
  • Access to the email address used for your business account.

Before installing

  • Close any older Billing Software window.
  • Keep at least 500 MB of free disk space.
  • Ask your Windows administrator for permission if your computer blocks software installation.
  • Do not delete the installer until you have confirmed the app opens correctly.
ImportantInstall the application on the computer where you will use the business data. The app stores its local database on that computer.

2. Install on Windows

  1. Open the folder containing the installer and double-click Billing-Software-Setup-1.0.1.exe. Use the latest version number if it is different.
  2. If Windows shows a security prompt, confirm that you want to run the installer. If your company manages the computer, contact your administrator.
  3. Choose the installation folder, or keep the suggested folder, then select Install.
  4. Wait for setup to finish. Keep Create a desktop shortcut selected if you want an easy shortcut.
  5. Select Finish, then open Billing Software from the desktop or Windows Start Menu.
First launchThe application starts its local service automatically. Give it a few seconds to load before trying again if the window opens slowly.

Sign in after installation

On the first screen, choose Log in if your account already exists. Choose Create an account if this is a new installation for your business.

3. Create your account

  1. Select Create an account.
  2. Enter company name, GST number, owner name, email, shop address, and a password.
  3. Submit the form. Check the email inbox for the one-time verification code.
  4. Enter the code in MotoDhandho. If the code expires, request a new code and use the newest message.
  5. Return to the login screen and sign in with your email and password.
Account securityDo not share your password or verification code. Keep the login email accessible because it is used for verification.

4. Set up your business

For the smoothest checkout, use this order: suppliers, products, then customers.

AreaWhat to doWhy it matters
SuppliersOpen Suppliers, select Add supplier, enter the supplier and company details, then select Save.A supplier is required when adding a product.
ProductsOpen Products, select Add product, choose a supplier, enter prices, stock, GST, and discount, then save.Saved products can be found by name or barcode during billing.
CustomersOpen Customers, select Add customer, enter name, contact number, email, and optional credit, firm, or GST details.Saved customers make receipts, credit, and returns easier to track.

When a product is saved, MotoDhandho creates its barcode automatically. Products can also be edited, searched, sorted, deleted, and printed as barcode labels.

Check before deletingProduct, customer, and supplier deletion requires confirmation. Deleting a record can affect future work, so verify the record before confirming.

5. Create your first bill

  1. Open Billing from the left navigation.
  2. Select a saved customer, or leave the bill as Walk-in Customer. You can add a new customer from the billing screen.
  3. Find a product by typing its name, or scan/type its barcode. A barcode scanner may paste the code directly into the barcode field.
  4. Check the cart. Adjust quantities or remove items if necessary.
  5. Open the payment area and choose Cash, Online, or Card. Add another payment row for a split payment.
  6. Enter the amount received. The screen shows the total, balance due, and change where applicable.
  7. Complete the sale. The invoice is saved and product stock is reduced automatically.
  8. Open the saved receipt and select Print if the customer needs a paper copy.

Split payment

For a Rs. 1,000 bill, enter Rs. 700 as Cash and Rs. 300 as Card. Complete the sale when the payment total covers the bill.

Cash change

For a Rs. 450 bill, enter Rs. 500 as cash received. MotoDhandho calculates Rs. 50 change.

6. Manage daily work

Dashboard

Use Dashboard to see revenue, orders, customers, inventory, payment mix, top-selling products, and low-stock items. Select This month, This year, or All time, then select Refresh for current figures.

Reports

Open Reports to filter invoices by date and GST information. You can view invoice details, print a receipt, export report data, and process eligible product returns. A return restores stock and adds the returned amount to the customer credit.

Navigation and appearance

The left menu opens Dashboard, Billing, Products, Customers, Suppliers, and Reports. Select the account picture for light/dark mode, database backup, import, download, and logout.

7. Backups and updates

Make a manual backup

  1. Select your account picture in the lower-left area.
  2. Select Export Database Backup or Download Backup.
  3. Store the downloaded backup in a secure folder or external drive.

Logout also requests a database backup before ending the session. Keep regular manual backups in a location separate from the computer.

Restore a backup

  1. Sign in and open the account menu.
  2. Select Import Database and choose a compatible backup file.
  3. Wait for the success message, then allow the application to reload.
Restore carefullyImporting replaces the current application data with the selected backup. Export the current database first if you may need it later.

Install an update

The installed app checks for releases at startup and periodically. When an update is available, choose Download update, then choose Back up and restart when you are ready. Save unfinished work first. You can choose Later and install from the update prompt again.

To check manually, open Help > Check for updates, or press Ctrl+Shift+U. Updates create and verify a pre-update database snapshot before installing. If that backup cannot be verified, the update is cancelled and the current app remains available.

8. Troubleshooting

ProblemTry this
The app does not openClose any existing Billing Software window, start it again from Start Menu, and wait a few seconds. Restart Windows if the local service is still unavailable.
Verification email did not arriveCheck spam/junk folders, confirm the email address, and request a new code. Use the newest code only.
A barcode is not foundCheck the code for extra spaces, confirm the product was saved with that barcode, or search by product name.
Update cannot installSave work, close other app windows, check free disk space, and try again. Do not remove the application data folder.
Backup or import failsConfirm you selected a compatible backup file and that Windows allows access to the chosen folder. Keep the original backup unchanged.
Support informationWhen contacting support, include the Billing Software version, the step that failed, and the exact message shown. Never send your password or verification code.
